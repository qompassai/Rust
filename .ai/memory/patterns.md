# Patterns — Rust

## Repo hygiene

- Seed zero-commit repos via Contents API PUT (blob endpoint 409s).
- Remove `__pycache__` before `git add -A` (py_compile artifacts).
- `push_via_api.py` cannot push repos with no local parent commit.
